# Security Policy

## Reporting a vulnerability

Please report vulnerabilities **privately** via
[GitHub Security Advisories](../../security/advisories/new).
Do **not** open a public issue for security problems.

We aim to acknowledge reports within 72 hours. Fixes ship as patch releases;
self-hosted installations are notified through the release feed
(commercial installations with the updater receive patches automatically).

## Supported versions

The latest minor release line receives security patches.
